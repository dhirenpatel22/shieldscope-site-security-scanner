# ShieldScope rule catalogue

Generated by `bin/rule-catalogue.php` from the check sources; `tests/test-s26-rule-catalogue.php` fails when it is out of date. IDs are numbered in source order within each check. Severity is the one the rule reports; findings labelled "Needs review" are pattern matches and are never Critical. See `docs/severity-rubric.md` for how severities are chosen and `docs/accuracy.md` for false-positive testing.
